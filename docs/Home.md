# English Grammar Mastery App

## 概要
**English Grammar Mastery App** は、日本の中学生レベルから英語学習をやり直したい大人まで、幅広い層を対象とした英文法学習アプリケーションです。
「5文型」と「品詞」という英語の基礎を徹底的に理解することに焦点を当て、体系的なカリキュラムとインタラクティブなクイズで学習をサポートします。

## 主な特徴
- **体系的なカリキュラム**: 英語の骨組みである「5文型」と「8大品詞」を基礎から学べます。
- **インタラクティブな学習**: 各レッスンには解説と確認クイズが含まれており、理解度をすぐに確認できます。
- **エキスパートチャレンジ**: 全レッスンをクリアすると解放される「エキスパートチャレンジ」モードで、総復習が可能です。
- **AIモード (Beta)**: Gemini AIを活用した無限クイズ生成機能で、飽きずに学習を続けられます。
- **視覚的な解説**: 豊富な図解とアイコンを使用し、直感的に文法構造を理解できます。
- **レスポンシブデザイン**: PC、タブレット、スマートフォンなど、あらゆるデバイスで快適に学習できます。

## 学習の流れ
1. **コース選択**: 「5文型マスター」または「品詞マスター」コースを選択します。
2. **レッスン学習**: 各トピック（例: SV文型、名詞）の解説を読み、理解を深めます。
3. **確認クイズ**: レッスンごとのクイズに挑戦し、全問正解を目指します。
4. **エキスパートチャレンジ**: コース内の全レッスンをクリアすると、高難易度の総復習モードに挑戦できます。

## 技術スタック
- **Frontend**: Vanilla JavaScript, HTML5, CSS3 (Glassmorphism Design)
- **Build Tool**: Vite
- **AI Integration**: Google Gemini API
- **Deployment**: GitHub Pages
