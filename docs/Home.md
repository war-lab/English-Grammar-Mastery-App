## 📖 はじめに

### このアプリについて

English Grammar Mastery Appは、日本の中学生が英語の基本5文型を効率的に学習できるWebアプリケーションです。

**主な特徴:**
- 🎯 5つの文型を体系的に学習
- 🤖 AI技術による無限の問題生成
- 📖 すべての問題に日本語解説付き
- 🎨 美しく直感的なUI
- 📊 進捗の自動追跡

### 対象ユーザー

- 中学生（英文法の基礎を学びたい方）
- 英語学習の初心者
- 文型の理解を深めたい方

## 🗺️ 学習パス

### レベル1: 基本をマスター

1. ✅ アプリをインストール
2. ✅ 第1文型（SV）のレッスンを完了
3. ✅ クイズで満点を取る
4. ✅ 進捗がダッシュボードに表示されることを確認

### レベル2: 全文型をマスター

1. ✅ 第2〜5文型のレッスンをすべて完了
2. ✅ 各クイズで満点を取る
3. ✅ Master Reviewが解放される

### レベル3: AIチャレンジ

1. ✅ [Gemini APIを設定](./API-Setup.md)
2. ✅ AIチャレンジモードに挑戦
3. ✅ 連続正解記録を更新

### レベル4: 開発者になる

1. ✅ [開発ガイド](./Development.md)を読む
2. ✅ 独自のレッスンを追加
3. ✅ 新機能を実装
4. ✅ コミュニティに貢献（Pull Request）
