## レッスンシステム

### 5つの文型レッスン

アプリでは英語の基本5文型を体系的に学習できます。

#### 第1文型 (SV)
- **構造**: Subject + Verb
- **説明**: 主語と動詞だけで完結する最もシンプルな文型
- **よく使う動詞**: run, walk, sleep, smile, exist, happen
- **例文**: "Birds fly." (鳥が飛ぶ)

#### 第2文型 (SVC)
- **構造**: Subject + Verb + Complement
- **説明**: 主語と補語がイコール関係（S = C）
- **よく使う動詞**: be, become, look, seem, feel, taste, smell
- **例文**: "She is a teacher." (彼女は先生です)

#### 第3文型 (SVO)
- **構造**: Subject + Verb + Object
- **説明**: 主語が目的語に対して動作を行う（S ≠ O）
- **よく使う動詞**: have, make, buy, eat, drink, watch, study
- **例文**: "I study English." (私は英語を勉強する)

#### 第4文型 (SVOO)
- **構造**: Subject + Verb + Object + Object
- **説明**: 「誰かに何かを〜する」という授与を表す
- **よく使う動詞**: give, show, teach, tell, buy, make, send
- **例文**: "He gave me a book." (彼は私に本をくれた)

#### 第5文型 (SVOC)
- **構造**: Subject + Verb + Object + Complement
- **説明**: 目的語と補語がイコール関係（O = C）
- **よく使う動詞**: call, name, make, keep, find, leave
- **例文**: "We call him Tom." (私たちは彼をトムと呼ぶ)

### ビジュアルダイアグラム

各レッスンには、文型の構造を視覚的に理解できるインタラクティブなSVGダイアグラムが含まれています。

## クイズ機能

### 基本クイズ

各文型レッスンには理解度を確認するためのクイズが用意されています。

#### 特徴

- **ランダム化**: 問題と選択肢の順序がランダムに表示されるため、暗記に頼らず真の理解が必要
- **即座のフィードバック**: 回答後すぐに正解・不正解が表示される
- **詳しい解説**: 正解時も不正解時も、なぜその答えになるのか詳しい日本語解説が表示される
- **進捗保存**: スコアは自動的にLocalStorageに保存される

#### 完璧スコアの達成

各トピックで満点（100%正解）を取ると、そのトピックが「完了」としてマークされ、ダッシュボードに✓ Completedバッジが表示されます。

## AI問題生成

### Gemini AI統合

Google Gemini APIを使用して、無限のバリエーションの問題を生成します。

### 4種類の問題タイプ

#### 1. 文型判定問題 (Pattern Identification)
英文を見て、どの文型に当てはまるかを選択します。

**例**:
```
問題: 次の英文の文型を答えなさい：
"She looks happy."

選択肢: SV / SVC / SVO / SVOO / SVOC
正解: SVC
```

#### 2. 穴埋め問題 (Fill in the Blank)
文の空欄に入る最も適切な語を選びます。

**例**:
```
問題: 次の文の空欄に入る最も適切な語を選びなさい：
"He ___ me a present."

選択肢: give / gives / gave / given / giving
正解: gave
```

#### 3. 誤り訂正問題 (Error Correction)
文法ミスを含む文を正しく訂正します。

**例**:
```
問題: 次の文の誤りを訂正しなさい：
"She make me happy."

選択肢: makes / made / making / to make / make
正解: makes
```

#### 4. 文型変換問題 (Transformation)
指定された文型に文を書き換えます。

**例**:
```
問題: 次の文を第4文型(SVOO)に書き換えなさい：
元の文: "I bought a book for her."

選択肢: [複数の選択肢]
正解: "I bought her a book."
```

### 日本語解説機能

すべてのAI生成問題には以下が含まれます：

- **日本語訳** (`japaneseTranslation`): 問題文や正解の文の自然な日本語訳
- **詳しい解説** (`explanation`): なぜその答えが正しいのか、文法的な観点から詳しく説明

### 難易度レベル

AI問題の難易度は連続正解数に応じて1〜10のレベルで自動調整されます：
- **Level 1-3**: 基礎レベル（簡単な語彙と構造）
- **Level 4-6**: 中級レベル
- **Level 7-10**: 上級レベル（複雑な構造と高度な語彙）

## Master Review Challenge

### 解放条件

5つの文型レッスンをすべて完了（満点取得）すると、特別なマスターレビューチャレンジが解放されます。

### ゲームモード

#### 通常チャレンジ
- Level 1からスタート
- 3問正解ごとにレベルアップ
- 不正解でゲームオーバー
- ベストスコア（連続正解数）を記録

#### AIチャレンジ
- Gemini AIによる問題生成
- 難易度が動的に調整
- 緑色の特別なUIテーマ
- 日本語解説付き

### 段階的難易度

連続正解数に応じて、UIのテーマカラーが変化します：
- **0-9問**: Tier 1（青）
- **10-19問**: Tier 2（紫）
- **20-29問**: Tier 3（ピンク）
- **30問以上**: Tier 4（金）

### 100問連続正解

100問連続で正解すると、特別な祝福画面が表示されます！�

## 進捗管理

### ダッシュボード

ダッシュボードには以下の情報が表示されます：

- **進捗率**: 完了したレッスン数 / 総レッスン数
- **レベル**: 現在の習熟度（未実装の場合は「Not Assessed」）
- **レッスンカード**: 各レッスンの状態とベストスコア

### レッスンカードの表示

各レッスンカードには以下が表示されます：
- **タイトル**: レッスン名
- **説明**: レッスン内容の簡単な説明
- **✓ Completedバッジ**: 満点を取得したレッスン
- **ベストスコア**: 過去の最高スコア

### データ永続化

すべての進捗データは`localStorage`に保存されます：

```javascript
{
  "level": "Not Assessed",
  "completedTopics": ["sentence-pattern-1-sv", ...],
  "scores": {
    "sentence-pattern-1-sv": 5,
    "sentence-pattern-2-svc": 4,
    ...
  }
}
```

## 隠し機能

### 🔓 Master Review 早期アンロック

通常、Master Reviewは5つのレッスンをすべて完了しないと解放されませんが、**隠しコマンド**を使用すると早期にアクセスできます！

#### 解除方法

1. ダッシュボードの「🔒 Master Review Locked」カードを見つける
2. **1秒以内に5回連続でクリック**する
3. カードが振動（シェイクアニメーション）するのを確認
4. 5回目のクリックでロック解除アニメーション
5. 自動的にMaster Reviewページに遷移

#### 永続化

一度ロック解除すると、`localStorage`に状態が保存されるため、ページをリロードしても解除状態が維持されます。

```javascript
localStorage.setItem('masterReviewUnlocked', 'true');
```

#### リセット方法

開発者ツールのConsoleで以下を実行：

```javascript
localStorage.removeItem('masterReviewUnlocked');
location.reload();
```
